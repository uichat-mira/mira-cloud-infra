# Mira Cloud Infrastructure

Mira's open-source deployment configuration for a small self-hosted cloud node.

> This repository contains no production secrets. Work is developed through `feat/* → dev → test → prod`; `main` is non-production and retained only as the bootstrap/default branch.

The first service is a loopback-only, Docker Compose-managed New API instance. Documentation and implementation are being prepared on a feature branch.
